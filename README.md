# L.D.C. 3D — 可交互数字犬

> 一只住在网页里的狗。**没有按钮，没有菜单 —— 按住它就行。**

🌐 **在线体验**：https://mrshder.github.io/pet-terminal-3d/

---

## 它是什么

一个 Three.js 实时 3D 场景。你按住那只狗，它会：

| 你的动作 | 它的反应 |
|---|---|
| 按住 | 抬头看你、身体前倾、尾巴翘起摆动、羁绊上涨 |
| 快速连点 | 烦躁累积 → 走开 → 冷静后自己回来 |
| 什么都不做 | 呼吸起伏、耳朵与头部随机摆动、眨眼 |
| 长时间不理它 | 羁绊缓慢衰减 |

**所有动作都是运行时用代码驱动骨骼算出来的**，没有预制动画文件。狗身上只有 10 根骨头
（`Root / Spine / Neck / Head / Tail1-2 / Leg_FL/FR/BL/BR`），"活着"的感觉来自
叠加的振荡器 —— 呼吸用正弦，头部游移用值噪声，尾巴摆动频率随情绪变化。

## 技术要点

**模型**：`public/models/dog.glb` —— 35 KB 低多边形，196 三角形，带骨骼。

**从狐狸改造成狗**（三处改动，都不动源文件）：

1. **配色** —— 源模型只有 4 种材质，在代码里按材质名重新着色成伯恩山犬配色
   （`AccentRed` → 炭黑背毛、`Paper` → 米白胸腹、`Ink` → 近黑四肢、`Gold` → 锈棕项圈牌）
2. **形体** —— 直接改几何体顶点。**注意：这些网格是蒙皮的，改 `mesh.scale` 没有效果**，
   因为顶点位置由骨骼矩阵决定。所以耳朵、口鼻、尾巴的形状是靠遍历 `position` 属性压扁的。
3. **尾巴姿态** —— 狐狸把尾巴举高，狗在静息时尾巴下垂、开心时才抬起，所以静息偏移量是反的。

**交互**：全屏监听 `pointerdown`，用 Raycaster 判断有没有真的点到狗身上 —— 点地板不算。

## 本地运行

```bash
npm install
npm run dev      # → http://localhost:5173
```

注意 `vite.config.ts` 里的 `base` 是 `/pet-terminal-3d/`（为了 GitHub Pages 子路径）。
本地开发若想用根路径，改成 `/`。

## 部署

推送到 `main` 会自动部署到 GitHub Pages（见 `.github/workflows/pages.yml`）。

## 相关

这是 [L.D.C.Terminal](https://github.com/MRSHDER/L.D.C.Terminal) 的 3D 版本。
那个项目是刻意做的**低分辨率像素风**（PixiJS、8~12 FPS、精灵图），
本项目换成了实时 3D，两者美术方向不同，各自独立。
